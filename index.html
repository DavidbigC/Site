RFQ execution

Variational

Variational’s request-for-quote API prices a specific trade size, so the execution app requests executable quotes for both legs of a pair. I directed the app build with curl_cffi for API access and set the per-pair polling cadence to 30 seconds during monitoring and one second during execution. That cut order-endpoint traffic from 86 to 8 requests per minute.
